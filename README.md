# AI Architect Mastery

A personal knowledge base and career prep tracker for growing into an AI/Software Architect role.

## Structure

- **00-Career** — career vision, resume, interview tracker, company research
- **01-DSA** — data structures & algorithms practice (arrays, hashmaps, trees, graphs)
- **02-LLD** — low-level design (SOLID, design patterns, mock interview problems)
- **03-System-Design** — high-level system design notes and case studies
- **04-Distributed-Systems** — distributed systems concepts
- **05-Architecture** — software/solution architecture notes
- **06-Agentic-AI** — agentic AI concepts, patterns, and experiments
- **07-AWS** — AWS notes and labs
- **08-Azure** — Azure notes and labs
- **09-Projects** — hands-on projects
- **10-Interview-Prep** — interview preparation material
- **11-Behavioral** — behavioral interview prep
- **12-ADRs** — architecture decision records
- **13-Notes** — general notes
- **assets** — diagrams, images, presentations used across the vault
