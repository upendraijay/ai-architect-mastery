# Day 3 Reflection

**Date:** August 11, 2026

## 1. What was the biggest OOP concept I learned today?

The biggest concept I learned was that **OOP is more than just creating classes and objects**. It is about designing software by assigning clear responsibilities to objects and defining how they interact through relationships such as **association, aggregation, composition, and inheritance**.

## 2. Which relationship (association, aggregation, composition) was hardest to understand?

**Association** was the hardest to understand.

I initially found it confusing to decide when two classes should have an association and when a method simply uses another object temporarily.

## 3. How is OOP different from simply writing classes?

Writing classes is only creating the building blocks.

**Object-Oriented Programming (OOP)** is about designing a system by:

- Assigning a single responsibility to each class.
- Defining how objects collaborate.
- Choosing the correct relationships (association, aggregation, composition, inheritance).
