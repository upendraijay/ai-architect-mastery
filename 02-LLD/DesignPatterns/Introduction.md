# Introduction to Design Patterns

## What is a Design Pattern and Why do we need patterns?

A design pattern is a proven way of organizing classes and objects to solve a common software design problem.

Every software application eventually faces common design problems.

For example:

- How should objects be created?
- How can we ensure only one instance of a class exists?
- How can one object notify multiple other objects?

Instead of reinventing the solution each time, developers can use an established approach that has been tested and refined over time.

---


## Why patterns should not be overused

Applying a pattern without a problem adds classes, and complexity for no benefit.
